# BITA TRAINER（パチスロ目押し・ビタ押し練習Webアプリ）

パチスロの目押し（ビタ押し）を高精度に練習できるWebアプリケーションです。
実機同様の回転（上から下への流れ）、1コマ16分割のディスクアップ仕様判定エンジン、実寸キャリブレーション機能を搭載しています。

## 🌟 主な機能

- **高精細ベクター図柄レンダリング**:
  - 解像度に依存しない鮮明なSVG図柄でリールドラムを直接描画。
  - 実機特有の光沢・スリット・稲妻・立体ロゴを忠実に再現。
- **実機準拠 1コマ16分割ビタ押し判定**:
  - 超ビタ（Marvelous! / 赤エリア 4/16分割、スコアボーナス+100pt）
  - 良ビタ（Excellent! / 緑エリア 7/16分割、スコアボーナス+50pt）
  - 並ビタ（Cool! / 青エリア 5/16分割、基本100pt）
  - 早い / 遅い（ミス判定・停止段ズレ表示）
  - リール制動距離（5分割分）を考慮した精密なスライスメーター（リアルタイムピン表示）。
- **収録機種**:
  - **ディスクアップ ULTRAREMIX**（20コマ仕様）: 中リール赤7中段、BAR下段、白7中段など
  - **スマスロ サンダーV**（21コマ仕様）: 左リール3連V（赤/黄）、単独V、BAR上段、中リールV中段など
- **練習モード & 本番モード**:
  - **練習モード**: 回転速度調整（10〜80 RPM）、ターゲット以外半透明化、ターゲット発光、目印強調、ガイドライン、自動ステップアップ
  - **本番モード**: 実機速度（80 RPM固定）・補助完全オフ・ゲーム数選択（10G/30G/50G/100G）・連続コンボ＆端末内ランキング
- **実機サイズ再現（実寸キャリブレーション）**:
  - クレジットカード（横幅85.6mm）基準でのピクセル/ミリ比率自動キャリブレーション。
  - 実機比率70%〜90%（デフォルト80%）のサイズ調整。

## 🚀 開発・起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build
```
